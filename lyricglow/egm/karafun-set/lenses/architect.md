# Lens: Skeptical Architect (design_critic persona, BRAINSTORM) — cost = phone CPU, memory, battery
1. **Blocker** — Shifter CPU + latency (U1/U2): 128-frame quanta ≈ 2.7 ms at 48 kHz on top of ~17 nodes + 3 analysers; quality shifters add 20–100 ms; `el.currentTime` knows nothing about worklet latency. → Hard CPU ceiling + measured latency on a named low-end device; latency in one constant subtracted only while key ≠ 0; bypass at 0 (worklet not in graph); range ±6 st; failure → hide Key; decide the library (SoundTouchJS LGPL) and licence before the PRD.
2. **Blocker** — Key/tempo vs clock and `playbackRate`. → Shifter works in the pitch domain only, never touches `el.playbackRate`; `engine.setRate` is the single tempo authority; test lyric drift < tolerance at 2.0× with key −2; set `preservesPitch` + prefixed variants explicitly; test Capacitor webviews.
3. **Major** — Placement: a non-phase-locked stage before the vocal chain leaks the vocal; after it, the shifter smears bass. → element → vocal chain → shifter (one worklet, both channels, shared phase) → analyser tap (moved after the shifter) → destination; residual-vocal test at key 0 and −2 within a few dB; mono detector upstream; keep the single `sourceFor` path.
4. **Major** — Queue memory / URL lifetime: one element per song leaks a source + chain each; swapping `src` keeps per-element state. → Cap (≈ 8 songs + bytes); one shared element, swap `src`; Files-only queue; revoke right after a song ends; `preload="metadata"` for non-current, preload only the next; reset/restore key, vocal level, rate explicitly per song; tell the user the queue is lost on reload.
5. **Major** — Song-end → next is racy: `play()` from an `ended` handler can be blocked by autoplay policy on iOS; `attachTransport` resets generation/songTime; pre-roll has no engine state. → AudioContext never closed, gesture-free next-song path tested on iOS/Capacitor; grade screen skippable/auto-dismissed in queue mode; one explicit intro state (card → countdown → playing) cancellable on pause/seek/skip/queue edit; one countdown source of truth; YouTube/Listen: card without countdown or none.
6. **Major** — Demo synth, guide hum and **scoring** use untransposed MIDI notes → a correct singer at key −2 scores 2 st off. → One shared `keyOffset` applied by PitchLane, scoring, demo, guide, with check:model fixtures; or disable scoring at non-zero key and say so.
7. **Major** — Thumb bar / toggle semantics (as other lenses): no sixth target; two-state toggle over one stored level; mono → disabled with reason.
8. **Nit** — Split delivery: (a) intro + queue + Vocals (React state + graph reuse), (b) Key behind a flag + device matrix; U3 = per-song reset; defer U9; move verify scripts into the repo.
