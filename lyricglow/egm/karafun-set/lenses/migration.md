# Lens: Migration & backward compatibility (implementation_readiness persona, BRAINSTORM)
No persisted data → no schema migration. Risks: audio graph, PWA/Capacitor delivery, thumb-bar test contract, single-track state.
1. **Blocker** — `sourceFor` binds element → source → vocal chain → destination once per element (API forbids a second `createMediaElementSource`); a lazily inserted or failing worklet can't be rebuilt. → The shifter is a permanently present, bypassable node built with the vocal chain; key 0 = true passthrough identical to today; worklet load failure → current chain, Key hidden; check key 0 matches today's analyser levels.
2. **Blocker** — Shifter latency vs lyric sync. → Key 0 = bypassed (latency exactly 0); non-zero key: state whether a fixed delay is compensated via `track.offset` or the clock, kept separate from the Lyrics-timing offset and mic latency.
3. **Major** — Speed must stay for all sources; Key only for local files; `playbackRate` stays the only tempo mechanism; set `preservesPitch` (+ `webkitPreservesPitch`) explicitly; browser matrix (iOS Safari, Chrome Android, desktop).
4. **Major** — Thumb-bar / `data-testid` contract: `btn-restart`, `mic-toggle`, `vocal-level`, `vocal-mono-note`, `tempo-slider`, `tempo-reset`, `tempo-value` stay valid or every rename lists the external verify-script update; re-verify 320 px; Vocals toggle reuses the existing level and mono note.
5. **Major** — Queue must be additive: empty queue = today's behaviour exactly; revoke only when an item leaves the queue; name the advance events; Sing again replays the current item; cap length/size; queue lost on reload is intended (consider a leave-page warning).
6. **Major** — PWA/SW + Capacitor: a worklet file must be emitted under `/assets/` (the `vercel.json` rewrite would otherwise serve HTML; the precache glob must include it); Capacitor iOS WKWebView is highest risk → same capability check as #1; build check that the worklet is in `dist` and the precache manifest.
7. **Major** — Rollback = redeploy + SW update; no flag mechanism. → Ship in independent slices (Vocals → intro → queue → Key last), each behind a build-time `VITE_FEATURE_*` constant or URL param, default off in native shells until device-tested; stage on a Vercel preview.
8. **Nit** — Songs with no intro/queue behave exactly as today; intro doesn't replace the first count-in unless the first line starts within the intro; demo/guide transpose or are disabled at non-zero key; check:model fixtures for new pure logic; move/document the verify-*.mjs flows.
