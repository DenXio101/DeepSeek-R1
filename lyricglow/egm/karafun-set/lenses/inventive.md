# Lens: Inventive Catalyst (BRAINSTORM)
**Ideal Final Result:** every new capability is a mode of an existing part or is free until used — the shifter costs zero at 0 semitones, the queue holds metadata not media, the bar keeps five targets, lyrics never drift.
1. **Blocker** — Shift quality vs CPU/latency. → Create the worklet lazily on the first non-zero key (not in the graph at 0); small-window WSOLA for ±1–2 st, heavier algorithm only for larger shifts; measure the fixed group delay once and subtract it like `track.offset`; crossfade the insertion; preload the module on first idle after a file is attached.
2. **Major** — Placement (U2). → source → vocal chain → shifter (stereo-linked) → analyser → destination; cancel first keeps the L/R phase maths; mono detection stays on the raw source; the analyser sees what is heard.
3. **Major** — Queue vs no-storage/memory. → Entries hold the File handle (lazy read), the track and per-song key/tempo; object URL only for the current item (+ at most one lookahead); cap ≈ 8; a stale File → skipped song with a note.
4. **Major** — Six targets vs 320 px. → Restart becomes a leading icon in the seek row (it is seek-to-zero); Vocals takes the slot; five targets, six functions, nothing < 44 px.
5. **Major** — Toggle vs slider vs mono. → The toggle is a view onto the same `useVocalLevel` value (on = remembered level, default 0.35; off = 0); hidden for YouTube/Listen; disabled with the existing note on mono.
6. **Major** — Intro vs sync and uncontrolled sources. → The intro is a pre-roll phase of the session: reuse the count-in dots in the cue slot with title/artist (SectionCard style), countdown drives `engine.play()` at zero, clock stays at 0 so no offset; YouTube/Listen get the card without countdown or delay; fade via a gain node, cut under reduced motion.
7. **Major** — Per-song key/tempo. → Key seeds from the previous song (singer's range), tempo resets to 1.0; "Apply key to all"; transpose DemoSynth, GuideSynth **and scoring** by the same semitones (integer add on MIDI notes) or a correct singer is scored 2 st off.
8. **Nit** — Lyrics auto-match for queued files is a pluggable later enrichment; entries allow an optional track; "no lyrics yet" state.
